## Reporting a Vulnerability

Please report (suspected) security vulnerabilities to our team. You can do this by submitting an issue with the "Security" label or contacting the maintainers directly.

When reporting a vulnerability, please provide the following details:
- A description of the vulnerability and its impact.
- Steps to reproduce the issue.
- Any potential fix or suggestion if you have one.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is needed, we will provide a timeline for the update.
